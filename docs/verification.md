별도 검토자가 중요 문제 4건을 확인했습니다. 장기 추천의 신규 학습 정체, 실제 입력·조립 콘텐츠 부재, 듣기 원문 선공개, 콘텐츠 ID 재배정 검사 부재입니다. 번역 오류 1건도 확인했습니다. **현재 테스트 70개 통과는 이 문제들이 없다는 증거가 아니며, 최종 완료로 판정하지 않습니다.** 재현 근거와 수정 순서는 [최종 검토 및 재개 지점](final-review.md)에 보존했습니다.

## 확인 범위와 한계

- 실제 일본어 음성 재생은 이 PC에 일본어 음성이 없어 확인하지 못했습니다. 음성 선택·지연 등록·재생 취소 분기는 테스트로 확인했습니다.

- 10~20분은 설계상 예상치이며 실제 두 사용자의 학습 속도를 측정한 값이 아닙니다.
