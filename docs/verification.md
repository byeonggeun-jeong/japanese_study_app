## 최종 검토 수정·UI 재점검·업데이트 — 2026-11-02

전체 84개 테스트, 타입·콘텐츠·빌드·NSIS 생성 통과. 기존 검토 중요 문제4건과 번역 오류를 수정했고 UI는 Toss 방향으로 변경했다. Emil Kowalski / Jakub Krehel 스킬에 따른 포커스·대비·좁은 화면·상태 표시 수정은 [UI 점검 결과](ui-review.md)에 기록했다.

새 0.1.1 설치본 업데이트 종료 코드0, 실행 파일 버전과 설정 화면0.1.1 확인. 사용자 학습 기록 SHA-256은 업데이트 전후 동일하다. 기존 자유 문장 세트의 3/10 진도와 1일 기록도 홈에서 확인했다. 앞선 ‘첫 진단 준비’ 기록 이후 생긴 사용자 진도는 초기화하지 않았다.

입력14개, 조립16개(N5/N4 각각8), 듣기66개, 선택1905개로 총량2,001개를 유지한다. 별도 테스트 프로필에서 입력→N5 조립→N4 조립→음성 없는 듣기 대체→완료 날짜 저장을 확인했다. 이 테스트는 사용자 진도에 기록하지 않았다.

## 확인 범위와 한계

- 실제 일본어 음성 재생은 이 PC에 일본어 음성이 없어 확인하지 못했습니다. 음성 선택·지연 등록·재생 취소 분기는 테스트로 확인했습니다.
- 친구 PC에서의 설치·성능·음성은 확인하지 않았습니다.
- 10~20분은 설계상 예상치이며 실제 두 사용자의 학습 속도를 측정한 값이 아닙니다.
- 콘텐츠 전 항목은 작성 에이전트가 확인하고 형식 검사를 수행했으며, 전문 교사·원어민의 독립 감수를 의미하지 않습니다.
