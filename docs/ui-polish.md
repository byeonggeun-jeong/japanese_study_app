# UI 다듬기 — 2026-11-02

요청: 최종 검토 문제를 먼저 해결한 다음 전체 UI/문구를 정리한다. 흰색·저채도 빨간색, Electron/React, 기존 학습 흐름과 저장 형식은 유지한다. 사지선다는 모든 화면에서 번호가 붙은 한 열 목록이다. 사용자의 앞선 질문 생략·진행 지시를 이어 받아 세부 시각 선택은 구현자가 맡는다.

## 방향과 기준

- design-taste-frontend app draw: Editorial greeting, seed 187280024, palette/type 유지. 짧은 일일 방문에 맞는 밝은 면과 일정한 숫자 굵기를 채택한다. 변경 추첨 없음. 앱 제목은 인사 대신 ‘오늘의 학습’을 유지한다. 브랜드의 빨간색 지시는 스타일의 빨간색 제한보다 우선한다.
- 이 앱의 얼굴: あ 문자 워드마크, 오늘 풀 실제 문제 수, 네 챕터의 진도와 연속 학습일. 외부 사진이나 가상 성과 수치는 쓰지 않는다.
- 홈의 질문: 오늘 무엇을 얼마나 공부할까? 실제 분량과 시작 버튼이 먼저 보인다.
- 연습의 질문: 지금 무엇을 답할까? 문제·선택지가 중심이고 번호는 선택 순서를 나타낸다.
- 챕터의 질문: 어떤 영역과 범위를 연습할까? 문자/문법/단어/문장에 범위와 시작을 붙인다.
- 기록의 질문: 얼마나 이어 왔고 무엇을 배웠을까? 실제 날짜와 챕터별 분량을 유지한다.
- 설정의 질문: 진단과 음성을 어떻게 바꿀까? 실제 가능한 행동과 필요한 안내만 남긴다.

실제 자료: 2,001문항, 189단원, 일일 최대15문항/자유10문항. 새 계정의 기록은 0이다. 검증용 브라우저는 메모리 API를 주입하며 Windows의 실제 기록에 접근하지 않는다.

## Toss 방향으로 재설계 — 사용자 피드백 반영

이전 Editorial greeting 시안은 사용자가 UI와 폰트를 거절했다. 유지 대상은 흰색·저채도 빨간색, 한 열 번호 선택지와 동작뿐이며 이전 시각 방향을 유지하지 않는다.

- 새 방향: Pastel consumer / seed 261539514. 아이콘만 있는 rail은 직관성을 해치므로 shell을 1회 redraw하여 Open plane(문자 메뉴)으로 변경했다.
- Pretendard Variable v1.3.9를 SIL OFL 1.1 라이선스와 함께 앱 안에 포함한다. 일본어는 Windows Yu Gothic으로 대체한다. 온라인 글꼴 서비스는 없다.
- Toss 공식 Typography의 제목 30/40, 본문 17/25.5 등 계층을 참고했다. 흰 카드, 20px 반경, 56px 행동 버튼, 채도 낮은 빨간색의 주 행동, 회색 보조 행동을 사용한다. Toss의 로고·전용 글꼴·자산은 복제하지 않는다.
- 홈: ‘오늘 풀 문제’의 실제 수와 한 개의 시작 버튼, ‘연속 학습’의 실제 기록을 두 카드에 배치한다. 최근7일 표시는 실제 완료 날짜에서 계산한다. 수식어나 슬로건을 삭제한다.
- 문제: 큰 문제 문구, 번호와 답만 있는 한 열 선택지. ‘다시 익혀 볼게요’→‘정답 확인’, ‘연습해 보기’→‘문제 풀기’ 등으로 변경한다.
- 완료: ‘학습한 내용’과 실제 복습 날짜만 표시한다. 챕터 설명은 ‘조사·동사 활용·문형’처럼 학습 내용을 직접 적는다.
