# 0.1.2 변경 — 2026-11-02

사용자 요청의 일곱 항목을 반영했다.

1. 사이드바의 ‘기초부터 N4까지’ 삭제.
2. ‘홈’을 ‘오늘의 학습’으로 변경.
3. 오늘의 학습 화면에서 중복된 자유 연습 블록 삭제.
4. 같은 자리에 히라가나·가타카나 문자표 진입 블록 추가. 문자표에서 기본46자, 탁음·반탁음25자, 요음33개를 각 문자 체계로 전환한다. や행·わ행의 빈 모음 자리는 비워 두고 ん/ン은 별도로 표시한다. 학습 기록은 변경하지 않는다.
5. 설정 문구 축약.
6. 시작점 다시 찾기의 진단 버튼을 설명 오른쪽에 배치. 좁은 화면에서는 제목이 자연스러운 단어 단위로 줄바꿈된다.
7. 앱 정보·콘텐츠 출처 분리. 앱 정보에 GitHub 프로필과 소스 코드 링크 추가. Electron에서는 정확히 이 두 URL만 기본 브라우저로 열고 그 외 새 창·페이지 이동은 계속 차단한다.

GitHub 계정은 연결된 프로필과 CLI 인증으로 확인했다. 사용자의 명시적 승인에 따라 전체 소스와 Git 기록을 https://github.com/byeonggeun-jeong/japanese_study_app 의 main 브랜치에 업로드하고 공개(PUBLIC) 저장소로 변경했다. 설치 파일과 개인 학습 기록은 Git 기록에 포함되지 않는다. 로컬 feature 브랜치는 유지한다.

검증: 타입 검사, 전체87개 테스트, 콘텐츠2,001문항/189단원·ID 검사, 빌드와0.1.2 NSIS 생성 통과. 문자표 전환·진도 불변·앱 정보 링크·외부 URL 허용 목록 테스트는 수정 전 실패 후 통과했다. 1440/768/390px 화면과 별도320×844px 화면에서 배치를 확인했다. 320px에서도 세 화면 모두 가로 넘침·잘린 컨트롤0개다.

문자표 검사 도구의 blank-gap은 일본어 표 셀을 일반 문단으로 세지 못해 발생했다. 실제 표 전체를 캡처해 셀을 확인하고 이 항목만 허용했다. 길이가 다른 세 문자표의 끝선과 무채색 문자 표시는 학습 자료의 구조를 따른다.

설치: Windows 형식 경로로0.1.2 설치 종료 코드0, 실제 설치 경로 실행 파일 버전0.1.2 확인. 진행 파일의 업데이트 전후 SHA-256이 동일해 기존 기록 보존을 확인했다. 설치본의 화면 조작은 Computer Use 요청 한도가 소진되어 이번에는 재검증하지 못했다. UI 기능은 브라우저 미리보기와 컴포넌트 테스트로 확인했다.
