# 학습 콘텐츠 범위와 출처

이 앱의 `N5`, `N4` 표시는 **JLPT 대비를 위한 자체 분류**입니다. JLPT가 공개한 고정 단어·문법 목록이라는 뜻이 아닙니다. 수준 설명은 [JLPT 공식 안내](https://www.jlpt.jp/e/about/levelsummary.html)를 참고했습니다.

| 영역 | 현재 수량 | 다루는 내용 |
| --- | ---: | --- |
| 문자 | 220문항, 27학습 단위 | 히라가나·가타카나의 기본 문자, 탁음·반탁음, 요음, 촉음, 장음. |
| 문법·표현 | 112문항, 25학습 단위 | 정중형, 조사, 존재, 비교, 요청, 경험, 가능, 이유, 조건, 추측, 수수, 명사화 등. 각 새 문형에 원본 예문 2개와 한국어 풀이가 있습니다. |
| 단어 | 1,304문항, 93학습 단위 | N5 674개, N4 630개. 표기·읽기·뜻과 선택형 연습을 포함합니다. |
| 문장 | 311문항, 34학습 단위 | N5 147개, N4 164개. 문법 예문을 다시 읽는 연습과 이동·식사·쇼핑·건강·학업·직장·집·약속 상황의 새 문장 90개를 포함합니다. |
| 합계 | 1,947문항, 179학습 단위 | `npm run validate:content`가 링크·정답·중복·수량을 검사합니다. |

## 자료 사용과 검수 상태

- 단어의 일본어 표기, 읽기, 학습 단계와 품사는 [OpenJLPT](https://github.com/evanclan/OpenJLPT)의 N5/N4 데이터에서 추렸습니다. 원본은 **CC BY-SA 4.0**이며, 이 앱의 `src/content/vocabulary/lexicon.json`도 같은 라이선스로 제공합니다. 원본의 Tatoeba 예문은 앱에 포함하지 않았습니다.
- 한국어 뜻은 영어 뜻과 일본어 표기를 각각 번역한 초안을 비교해 작성했습니다. 자동 번역에는 오역이 있을 수 있어 일부 명백한 항목을 수정했으며, **전체 1,304개 항목의 독립적인 사람 감수는 아직 끝나지 않았습니다.** 뜻이 어색한 항목은 배포 전에 추가로 교정해야 합니다.
- 문법 설명과 예문, 생활 문장은 이 프로젝트에서 새로 작성했습니다. 일반적인 짧은 표현은 다른 교육 자료에도 우연히 나타날 수 있습니다. 일본어 교사 또는 원어민의 전문 감수는 받지 않았습니다.
- 문제 선택지는 중복과 정답 포함 여부를 자동 검사합니다. 선택지가 학습적으로 그럴듯한지, 문장 번역이 자연스러운지는 표본 검토만 끝났습니다.
- 일본어 음성이 없는 PC에서는 문장 읽기와 선택형 문제를 텍스트로 풀 수 있습니다. 듣기 분류 문항도 이때는 화면의 원문이 표시됩니다.

## 보강할 점

1. 어휘 전체의 한국어 뜻과 한자 읽기를 사전 대조 및 사용자 피드백으로 교정합니다.
2. 촉음·장음의 연습 변형과 어휘별 자연스러운 사용 문맥을 보강합니다.
3. 추측·조건 등 N4 문법의 오답 선택지를 문형별로 다듬고, 실제 소리만 듣고 이해하는 청해 문항을 추가합니다.
