# 학습 콘텐츠 범위와 출처

이 앱의 `N5`, `N4` 표시는 **JLPT 대비를 위한 자체 분류**입니다. JLPT가 공개한 고정 단어·문법 목록이라는 뜻이 아닙니다. 수준 설명은 [JLPT 공식 안내](https://www.jlpt.jp/e/about/levelsummary.html)를 참고했습니다.

| 영역 | 현재 수량 | 다루는 내용 |
| --- | ---: | --- |
| 문자 | 220문항, 27학습 단위 | 히라가나·가타카나의 기본 문자, 탁음·반탁음, 요음, 촉음, 장음. |
| 문법·표현 | 130문항, 30학습 단위 | N5 58개, N4 72개. 활용, 조사, 비교, 요청, 경험, 가능, 조건, 추측, 수수, 수동·사역, 명사화, 높임말 등. 각 문형에 설명·원본 예문 2개가 있습니다. |
| 단어 | 1,304문항, 93학습 단위 | N5 674개, N4 630개. 모든 단어에 표기·읽기·한국어 뜻과 새로 작성한 사용 문맥을 포함합니다. |
| 문장 | 347문항, 39학습 단위 | N5 159개, N4 188개. 문법 적용과 이동·식사·쇼핑·건강·학업·직장·집·약속 상황의 문장 90개를 포함합니다. |
| 합계 | 2,001문항, 189학습 단위 | `npm run validate:content`가 링크·정답·중복·수량을 검사합니다. |

학습 단위는 정적 콘텐츠를 묶는 기준입니다. 오늘의 학습은 복습 기한과 진단 결과에 따라 여기에서 최대 15문항을 고르므로, 한 학습 단위가 하루 분량과 항상 일치하지는 않습니다. 자유 연습에서는 문자 체계 또는 N5/N4 범위를 선택합니다.

## 자료 사용과 검수 상태

- 단어의 일본어 표기, 읽기, 학습 단계와 품사는 [OpenJLPT](https://github.com/evanclan/OpenJLPT)의 N5/N4 데이터에서 추렸습니다. 원본은 **CC BY-SA 4.0**이며, 이 앱의 `src/content/vocabulary/lexicon.json`도 같은 라이선스로 제공합니다. 원본의 Tatoeba 예문은 앱에 포함하지 않았습니다.
- 한국어 뜻의 초기 번역 초안을 작성 에이전트가 전 항목 확인하고, 이번 재개 작업에서 387개의 뜻을 교정하거나 다듬었습니다. 1,301개 공개 자료 기반 항목과 초기 3개 항목 모두에 새 사용 문맥을 작성했습니다. 예: 暑い=덥다, まずい=맛없다, 一月(ひとつき)=한 달, 御主人=남편분, 訳(わけ)=이유·사정, 沸かす=끓이다 / 沸く=끓다.
- 문법 설명과 예문, 생활 문장은 이 프로젝트에서 새로 작성했습니다. 일반적인 짧은 표현은 다른 교육 자료에도 우연히 나타날 수 있습니다. 일본어 교사 또는 원어민의 전문 감수는 받지 않았습니다.
- 문제 선택지는 중복과 정답 포함 여부를 자동 검사하고, 화면에서 순서를 섞습니다. 선택지는 같은 단계의 다른 어휘·문장으로 구성하여 학습용으로 사용하며 난도는 실제 JLPT 문항과 다를 수 있습니다. 전문 교사나 원어민의 감수 결과를 뜻하지 않습니다.
- 일본어 음성이 없는 PC에서는 문장 읽기와 선택형 문제를 텍스트로 풀 수 있습니다. 듣기 분류 문항도 이때는 화면의 원문이 표시됩니다.

## 대조한 참고 자료

- [일본국제교류기금 Irodori 문법 해설](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf): 동사 활용·가능·수동 등 기초 문법 확인. 문항과 예문은 복제하지 않았습니다.
- [디지털대사천 등의 訳 항목](https://kotobank.jp/word/%E8%A8%B3-647771), [沸く 항목](https://kotobank.jp/word/%E6%B2%B8%E3%81%8F-664873): 읽기에 따라 뜻이 달라지는 어휘와 자동사 구별을 표본 대조했습니다.

## 사용 범위

텍스트 기반 N4 대비와 일상 표현 학습을 제공합니다. 일본어 기기 음성은 읽어 주기 보조이며, 녹음 음성만 듣는 시험 모의고사와 발음 채점은 제공하지 않습니다. 피드백을 받으면 안정적인 문항 ID를 유지하며 오역·어색한 문맥을 수정합니다.
