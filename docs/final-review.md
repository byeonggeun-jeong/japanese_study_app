# 최종 검토 수정 결과

현재 버전은 0.1.2입니다. 문자표·설정·메뉴 변경과 저장소 연결은 [0.1.2 변경](changes-0.1.2.md)을 참고하세요. 아래는 0.1.1의 최종 검토 수정 이력입니다.

2026-11-02 기준, 이전 검토의 중요 문제 4건과 교육 번역 오류를 수정했다. 설치본은 **0.1.1**이며 이 PC에 업데이트했다. 이전 검토 대상은 e887c6d, 중간 저장 기록은 6cf234e다.

| 검토 문제 | 수정 | 증거 |
| --- | --- | --- |
| 복습 포화로 450문항에서 신규 정체 | 가능한 각 챕터의 신규 한 자리 확보, 숙달 복습 간격 최대365일, N5 완료 후 N4 | 실제 2,001문항을 하루15개 이하로 1,500일 실행해 전체 도달·복습 적체 검사 통과 |
| 실제 입력/조립 문항 없음 | 입력14개, N5/N4 조립 각8개, 조사 빈칸4개. 조립 원본 조각은 정답 순서로 저장하고 UI에서 섞음 | 콘텐츠 모드·불가능한 조립·IME 회귀 검사. 별도 Electron 프로필의 실제 입력·양 단계 조립 확인 |
| 듣기 원문을 먼저 표시 | 일본어 음성이 있으면 숨기고 원문 보기/답변 후 공개, 음성이 없으면 텍스트 대체 | Practice 두 분기 테스트. 실제 음성 없는 Electron 텍스트 대체 확인 |
| ID 삭제/재배정 검증 없음 | 현재 2,001개 ID와 의미 기준 목록을 고정하고 패키징 검사에 연결 | ID 이름 변경·문법 의미 재배정 실패 검사. 일반 빌드에서 기준 목록 자동 생성 안 함 |
| てもらいました를 요청으로 오역 | 선생님이 고쳐 준 결과와 친구가 찍어 주는 도움으로 예문 두 개 수정 | 실제 문장 정답 데이터 회귀 검사 |

번역은 학습 결과를 잘못 가르치므로 Important로 재분류해 같은 수정 과정에 포함했다. 추가 검토자를 다시 호출하지 않고 실패 재현→수정→전체 테스트로 확인했다.

후속 UI 요청에 따라 Toss 방향으로 재구성하고, Emil Kowalski 및 Jakub Krehel 스킬로 다시 점검했다. [UI 점검 결과](ui-review.md), [디자인 기록](ui-polish.md), [검증 기록](verification.md), [구현 판단](implementation-decisions.md)을 함께 본다.

`npm run make`의 전체 **84개 테스트**, 타입·콘텐츠·빌드·설치 파일 생성 통과. 설치 종료 코드0, 설치된 실행 파일/설정 화면 버전0.1.1, 업데이트 전후 사용자 진도 파일 해시 일치.

검증 한계: 실제 일본어 음성(기기에 없음), 친구 PC, 전문 교사·원어민 감수, 실제 화면 읽기 프로그램과 설치본 200% 확대 확인. 새 기능을 생략한 판단이 아니라 확인 범위의 한계다.
