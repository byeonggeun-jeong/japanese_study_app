# 일본어공부 Windows 앱 설계

작성일: 2026-11-01

## 의도와 사용자

두 사람이 각자의 Windows PC에서 매일 10~20분씩 일본어를 공부한다. 한 사람은 듣기와 말하기에 익숙하지만 히라가나·가타카나 읽기가 느리고, 다른 한 사람은 네 영역 모두 기초부터 시작한다. 앱은 각자의 현재 수준에 맞는 오늘의 학습을 정하고, 연속 학습일과 누적 성장을 보여 주어 꾸준히 사용할 이유를 만든다. 첫 완성본의 범위는 문자부터 JLPT N4 대비 수준까지이며, 장기 목표는 N3이다. 시험 대비와 일상 회화 표현을 함께 다룬다.

## 확정된 요구

- Windows에서 실행하는 Electron 앱. 두 사람은 각자 설치하고 각자의 PC에 진도를 저장한다.
- 첫 실행에 짧은 진단 문제를 풀어 시작 지점을 정한다.
- 앱이 매일 10~20분 분량의 학습을 제시한다. 네 챕터의 자유 연습도 가능하다.
- 챕터는 ① 히라가나·가타카나 무한 반복 ② 문법 ③ 단어 ④ 문장이다.
- 오늘의 학습 또는 자유 연습의 한 묶음을 완료하면 그 날짜를 학습일로 기록한다. 연속 학습일은 필수다.
- 한자는 단어의 뜻·읽기 및 문장 속 인식으로 다룬다. 손글씨 연습은 없다.
- 첫 버전에는 마이크 인식, 발음 평가, AI 자유 대화가 없다. 나중에 음성 활동을 추가할 수 있도록 콘텐츠의 활동 종류를 구분한다. 사용하지 않는 음성 기능을 미리 구현하지 않는다.
- 사용 중 유료 API나 구독 비용이 발생하면 안 된다. 일본어 음성은 비용 없는 Windows 음성 기능을 우선 사용하며, 필요한 무료 음성팩 설치 안내를 제공한다.
- 흰색과 채도 낮은 빨간색을 기본 UI 색상으로 사용한다.
- 커리큘럼, 예문, 문제는 새로 작성한다. 교재나 공식 문제를 복제하지 않는다.

## 설계 가정과 한계

- 사용자 인터페이스와 해설은 한국어, 학습 대상 텍스트는 일본어로 작성한다. 한국어로 대화하는 두 사용자를 위한 설계자의 선택이며 설계 승인 때 확인받는다.
- 계정, 친구 간 기록 동기화, 서버는 첫 버전에 넣지 않는다. 두 PC의 기록은 독립적이다. 인터넷 연결을 허용하지만 핵심 학습과 진도 저장에는 필수로 요구하지 않는다.
- JLPT는 현재 수준별 단어·한자·문법 전체 목록을 공개하지 않는다. 따라서 “N4까지”는 공식 수준 설명과 출제 영역을 기준으로 구성한 **N4 대비 커리큘럼**을 뜻한다. 특정 시험 범위를 100% 적중한다고 표시하지 않는다. 근거: [JLPT 공식 FAQ](https://www.jlpt.jp/e/faq/index.html), [수준별 능력 요약](https://www.jlpt.jp/sp/e/about/levelsummary.html).
- 음성 합성은 PC에 노출된 일본어 음성이 있는 경우에만 제공한다. 음성이 없으면 읽기·텍스트 문제는 정상 작동하고 설정 안내를 보여 준다. 음성 기능은 사용자 PC 한 대에서 확인하며, 친구의 PC에서 같은 음성이 제공되는지는 확인할 수 없다. [Web Speech API 음성 목록](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices), [Windows 언어 기능 설치](https://support.microsoft.com/en-us/windows/hardware/input-devices/manage-the-language-and-keyboard-input-layout-settings-in-windows).

## 콘텐츠 제작 기준

- 공식 고정 목록이 없으므로 다음 수치는 **첫 완성본을 검증하기 위한 자체 목표**다. N5·N4를 합쳐 단어 최소 1,200개, 문법·표현 최소 100개, 서로 다른 원본 예문·짧은 대화 최소 300개, 추천 학습 세트 최소 120개를 제작한다. 각 세트는 평균 10~20분으로 구성한다.
- 콘텐츠 목록에는 문자 체계, N5 기초, N4 확장 단계와 각 항목이 연결된 학습 개념을 기록한다. 공식 N4 수준 설명과 주요 문제 유형에 대응하는 범위표를 만든다. 단순 수량 달성만으로 완료로 보지 않는다.
- 각 문법·표현에는 한국어 설명, 최소 2개의 원본 예문, 정답 근거가 포함된 연습이 있다. 단어에는 일본어 표기, 읽기, 한국어 뜻, 사용 문맥을 기록한다. 문제는 정답과 오답 선택지의 타당성을 검토한다.
- 제작자가 모든 항목을 1차 검토하고, 다른 방식으로 독립 재검토한다. 형식·중복·누락은 자동 검사한다. 일본어 원문과 해설은 신뢰할 수 있는 사전·문법 자료와 대조하며, 의심스러운 항목은 배포 대상에서 제외하거나 수정한다. 전문 교사의 감수를 거쳤다고 표시하지 않는다.

## 고려한 접근

1. **단계형 코스 + 오답 복습 — 선택됨.** 진단 결과로 시작 단계를 정하고, 매일 새 내용과 복습을 섞는다. 학습 경로가 명확하고 콘텐츠 및 추천 결과를 검증하기 쉽다. 세밀한 개인화는 오답과 복습 기한의 우선순위로 구현한다.
2. **문항별 완전 적응형 코스 — 선택하지 않음.** 매 답변마다 다음 주제를 바꿀 수 있지만 학습 경로가 불투명하고 알고리즘·콘텐츠 검증 비용이 커진다.

## 학습 구조

### 첫 실행 진단

- 문자 인식, 기초 단어, 기초 문법, 짧은 문장 이해를 골고루 확인하는 짧은 진단이다. 초보자가 답을 계속 틀릴 경우 불필요한 고급 문제를 오래 풀지 않도록 단계별로 종료한다.
- 결과는 챕터별 출발점으로 저장한다. 듣기·말하기에 익숙한 사용자의 문자 약점이 다른 영역의 출발점까지 일괄적으로 낮추지 않도록 한다.
- 결과 화면은 평가 점수보다 “어디서 시작하고 무엇을 먼저 연습하는지”를 설명한다. 설정에서 진단을 다시 할 수 있다.

### 네 챕터

| 챕터 | 핵심 활동 | 범위 |
| --- | --- | --- |
| 문자 | 글자 보고 읽기 고르기/입력, 소리 듣고 글자 고르기, 틀린 글자 가중 반복 | 히라가나·가타카나 기본, 탁음·반탁음, 요음, 촉음, 장음 |
| 문법 | 짧은 설명과 예문, 알맞은 형태 고르기, 빈칸, 어순 배열 | 기초 문장 구조부터 N4 대비 문형까지 단계별 |
| 단어 | 뜻·읽기 매칭, 한자 단어 읽기, 문맥에 맞는 단어 고르기 | 일상 생활 및 N5~N4 대비 어휘, 한자 인식 포함 |
| 문장 | 짧은 대화·문장 읽기, 응답 고르기, 문장 조립, 음성 듣고 이해하기 | 앞의 문법·단어를 재사용한 일상 상황 및 N4 수준 독해·청해 |

- 문장 챕터는 시험 대비용 독해·청해와 실제 대화 상황을 함께 다룬다. 따라 말하기는 사용자가 스스로 연습하며 앱이 음성을 채점하지 않는다.
- 신규 항목은 설명 → 예시 → 연습 → 정답과 해설 → 나중에 복습 순서로 제공한다. 오답은 정답만 보여 주지 않고 왜 틀렸는지 한국어로 설명한다.
- 문자 챕터의 “무한 반복”은 정해진 문제 풀이 뒤 계속하기로 이어지는 방식이다. 한 묶음의 완료 지점은 명확히 표시한다.

### 오늘의 학습과 복습

- 추천 세트는 **기한이 된 복습 → 약한 문자/개념 → 현재 단계의 새 내용 → 문장 적용** 순서로 구성한다. 예상 시간은 10~20분이다. 복습이 많으면 새 내용을 줄인다.
- 기존 항목을 맞히면 다음 복습 간격이 늘고, 틀리면 짧은 간격으로 다시 나온다. 같은 문제만 즉시 반복해 정답을 외우는 현상을 줄이도록 표현이나 문맥을 바꾼 변형 문제를 사용한다.
- 자유 연습에서는 챕터와 범위를 선택한다. 오늘의 추천 세트를 완료한 후에도 자유 연습을 계속할 수 있다.
- 학습 중 앱을 닫으면 완료한 문항의 결과를 보존하고 미완료 세트를 이어서 풀 수 있다. 완료 전에는 그 세트가 학습일로 집계되지 않는다.

## 성취 기록

- 홈에서 오늘 학습 여부, 현재 연속 일수, 최장 연속 일수, 누적 학습일을 표시한다. 보조 지표는 익힌 단어·문법 수와 복습 성공 수다.
- 학습일은 PC의 현지 달력 날짜를 기준으로, 추천 또는 자유 연습의 **한 묶음을 완료한 날**이다. 하루에 여러 묶음을 끝내도 학습일은 하루만 증가한다.
- 하루를 건너뛰면 현재 연속 일수는 끊기고 최장 기록은 남는다. 첫 버전에는 연속 기록 보호권이나 유료 보상 시스템을 넣지 않는다.
- 학습 완료 화면에는 해당 세트에서 익힌 내용과 다음 복습 대상을 보여 준다. 누적 기록은 달력과 챕터별 진도로 확인한다.

## 화면과 시각 방향

- 주요 화면: 첫 실행 진단, 홈/오늘의 학습, 네 챕터 목록 및 자유 연습, 문제 풀이, 세트 완료, 진도/달력, 설정.
- 홈의 첫 번째 행동은 “오늘의 학습 시작/이어하기”다. 연속 기록과 오늘의 분량은 바로 보이고, 상세 통계는 진도 화면에서 본다.
- 흰색 바탕, 어두운 본문 글자, 채도 낮은 빨간색 강조를 사용한다. 제안 토큰: 배경 `#FBF9F8`, 카드 `#FFFFFF`, 본문 `#262224`, 주요 강조 `#A54850`, 약한 경계 `#E8DDDC`. 주요 강조색 위 흰 글자는 약 5.77:1 대비다. 실제 UI 조합별 대비를 다시 검증한다.
- 한국어와 일본어의 글리프 가독성을 위해 Noto Sans KR/JP 계열을 우선 검토한다. 본문 16px 이상, 일본어 문제 텍스트는 더 크게 표시한다. 문자 정답을 색상만으로 구분하지 않는다.
- 키보드로 모든 학습 행동을 수행할 수 있게 하고 포커스를 명확히 보여 준다. 진행 중인 문제 수와 정답 피드백을 명시한다. 움직임 감소 설정을 존중한다.
- UI Pro Max 검색에서 성인용 단순한 레이아웃, 한국어·일본어 가독성, 명확한 진행 표시와 키보드 탐색 지침을 채택했다. 자동 추천의 홍보 페이지 패턴, 어린이용 스타일, 요청 색상과 다른 팔레트는 적용하지 않는다.

## 구현 방향

- Electron 안에 TypeScript 기반 UI를 실행한다. React와 Vite를 기본 후보로 두되, 최종 라이브러리 버전과 패키징 방법은 구현 계획에서 확인한다.
- 커리큘럼과 원본 문항은 버전이 있는 정적 콘텐츠 파일로 앱에 포함한다. 각 항목에는 안정적인 ID, 챕터, 단계, 학습 개념, 문제 유형, 정답, 해설, 음성으로 읽을 텍스트(해당할 때)를 둔다. 새 음성 문제 유형은 나중에 추가할 수 있지만 초기에는 마이크 코드가 없다.
- 개인 진도, 진단 결과, 답변 기록, 복습 기한, 학습일은 Electron의 사용자 데이터 위치에 저장한다. 앱 업데이트로 콘텐츠가 바뀌어도 기존 진도가 연결되도록 안정적인 콘텐츠 ID를 유지한다. 저장 전후 검증과 백업/내보내기는 데이터 손실 위험을 줄이는 최소 범위로 설계한다. [Electron 사용자 데이터 경로](https://www.electronjs.org/docs/latest/api/app).
- Windows에 제공되는 일본어 음성이 노출되면 음성 합성을 사용한다. 앱 시작과 설정 화면에서 사용 가능 여부를 확인하며, 없을 때는 무료 음성 기능 설치 안내를 제공한다. 유료 서비스 및 API 키는 요구하지 않는다.
- 배포물은 Windows 설치 파일로 제공한다. 개발 환경 없이 두 PC에서 설치·실행할 수 있어야 한다.

## 첫 완성본의 검증 기준

1. Windows 설치 파일을 사용자 PC 한 대에서 설치·실행·재시작하고 진도 보존을 확인한다. 서로 다른 사용자 데이터 위치를 사용한 테스트로 기록 분리를 확인한다. 친구 PC에서의 설치·음성 결과는 검증 범위에 포함하지 않는다.
2. 진단에서 문자에 약한 사용자와 모든 영역에 약한 사용자가 서로 다른 시작 학습을 받는다.
3. 네 챕터를 모두 학습할 수 있고, 문자 반복은 계속 이어지며, 기초부터 N4 대비 단계까지 순서대로 도달할 수 있다.
4. N4 대비 콘텐츠 목록이 공식 N4 수준 설명과 주요 문제 유형의 언어지식·읽기·듣기 영역을 빠짐없이 대응한다. 각 학습 개념에는 원본 설명·예문·연습·해설이 있으며 일본어와 한국어를 검수한다. 공식 시험 문제나 저작권 있는 교재를 복제하지 않는다.
5. 추천 세트는 10~20분 분량으로 구성되고, 오답·복습 기한이 다음 추천에 반영된다.
6. 추천 또는 자유 연습 세트를 완료한 날만 연속 기록에 반영된다. 날짜 경계, 중복 완료, 하루 건너뛰기, 재시작 후 집계가 일관된다.
7. 비용 없이 일본어 음성이 있는 PC에서 듣기 문제가 작동한다. 음성이 없는 PC에서는 설치 안내가 보이고 다른 학습은 계속 가능하다.
8. 핵심 흐름을 키보드만으로 완료할 수 있고, 텍스트 대비 및 축소/확대에서 읽기 문제가 없다.

## 후속 범위

- N3 커리큘럼은 안정적인 콘텐츠 ID와 단계 구조에 추가한다.
- 마이크 인식, 발음 피드백, AI 자유 대화는 별도 설계 후 추가할 수 있는 후보이며 첫 완성본의 약속이 아니다.

## 첫 중간 저장 기록 — 2026-11-01

사용자 요청에 따라 이 지점에서 작업을 일시적으로 마무리한다. **설계 승인 범위가 줄어든 것은 아니며, 설치 가능한 첫 완성본은 아직 아니다.** Git 작업 브랜치는 `feature/japanese-study-app`이다. 이어서 작업할 때는 [구현 계획](../plans/2026-11-01-japanese-study-windows.md)의 9단계부터 진행한다.

### 완료하고 검증한 부분

- 보안 설정을 적용한 Electron + React + TypeScript 앱 셸, Windows 로컬 진도 파일과 백업 복구, 날짜별 연속 기록.
- 챕터별 첫 실행 진단, 15문항 추천 학습, 오답 복습, 10문항 자유 연습, 중단 후 이어 풀기, 홈·챕터·진도·설정 화면.
- 흰색·채도 낮은 빨간색 화면, 키보드 포커스 표시와 기본 반응형 배치. 실제 개발용 Electron 창에서 진단 첫 화면과 Tab 이동을 확인했다.
- 일본어 기기 음성이 있을 때의 읽어 주기와 음성이 없을 때의 텍스트 학습 안내. 현재 PC의 Windows 음성 목록에는 한국어 음성만 확인되어 일본어 음성 재생은 실제로 검증하지 못했다.
- 콘텐츠 초안: 문자 220문항, 문법·표현 112문항, 단어 1,304문항, 문장 311문항으로 총 1,947문항·179학습 단위. 현재 상태의 링크, 정답 포함, 선택지 중복, 고유 ID와 목표 수량은 자동 검사를 통과했다. 세부 범위와 출처는 [콘텐츠 범위](../../content-coverage.md)에 기록했다.

### 아직 필요한 부분

1. **콘텐츠 품질 검수:** 단어 1,304개의 한국어 뜻은 공개 어휘 표기·읽기를 바탕으로 만든 번역 초안이다. 발견한 오역 일부를 고쳤지만 전체의 독립 검수, 단어별 자연스러운 사용 문맥, 문법·문장 오답 선택지 검수는 끝나지 않았다. 수량 검사 통과를 교육 품질 검증으로 간주하면 안 된다.
2. **학습 흐름 보강:** 새 문형의 설명과 두 예문은 데이터에 있으나 현재 문제 화면은 예문 한 개와 선택지를 먼저 보여 주고 자세한 설명은 답변 뒤에 보여 준다. 원래 설계한 ‘설명 → 예시 → 연습’ 순서와 챕터별 세밀한 진도 표시를 마무리해야 한다. 앱을 자정 넘게 켜 둔 경우 오늘 날짜를 갱신하는 처리도 필요하다.
3. **배포·실사용 검증:** Windows 설치 파일 생성, 설치 후 진단 → 학습 완료 → 연속 기록 → 자유 연습 → 재시작 보존 확인, README와 데이터 백업 안내는 10단계에 남아 있다. 친구의 PC는 접근할 수 없어 별도 설치 확인이 필요하다.

이 상태는 다음 작업을 이어가기 위한 **중간 구현본**이다. 최종 완료 또는 N4 전 범위의 교정 완료라고 표시하지 않는다.

## 재개 후 구현·설치 검증 — 2026-11-01

- 어휘 1,304개 전체의 뜻과 읽기를 확인하고 사용 문맥을 추가했다. 문법 활용·수동·사역·높임말을 보강해 문자 220, 문법·표현 130, 단어 1,304, 문장 347로 총 **2,001문항·189학습 단위**를 포함한다. 전문 교사나 원어민 감수를 받은 콘텐츠라고 표시하지 않는다.
