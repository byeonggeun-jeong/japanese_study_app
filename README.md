# 일본어공부

**0.2.0 · 로컬 웹앱**

Windows에서 매일 10~20분씩 일본어를 공부하는 무료 앱입니다. 히라가나·가타카나,
문법, 단어, 문장을 기초부터 N4 수준까지 연습합니다. 기존 UI와 문자표, 연속 학습 기록을 유지합니다.
화면은 브라우저에서 열리고 기록은 이 PC의 파일에 저장됩니다. 계정·구독·유료 API·클라우드 동기화는 없습니다.
Electron EXE 대신 공식 Node.js와 기본 브라우저를 사용하며 Smart App Control 설정을 변경하지 않습니다.

## 실행하기

필요한 프로그램: **Node.js 24 LTS 이상**, 최신 Microsoft Edge 또는 Chrome.
[Node.js 공식 사이트](https://nodejs.org/)에서 LTS Windows 설치 파일로 한 번 설치하세요.
공식 배포본을 사용하며 앱 전용 EXE·코드 서명 인증서는 필요하지 않습니다.
PC의 조직 정책이 Node.js 자체를 제한한다면 별도의 정책 확인이 필요합니다.

1. [공개 빌드](https://github.com/byeonggeun-jeong/japanese_study_app/actions/workflows/windows-build.yml)의
   최근 성공한 실행에서 `local-web-…` 산출물을 다운로드합니다. GitHub 로그인이 필요할 수 있습니다.
   개발 PC에서는 `dist/JapaneseStudy-0.2.0-LocalWeb.zip`을 사용합니다.
2. 산출물 안의 `JapaneseStudy-0.2.0-LocalWeb.zip`을 **전체 압축 해제**합니다.
3. 압축 해제한 폴더의 **시작.cmd**를 더블클릭합니다.
4. 브라우저에서 **http://127.0.0.1:3217**이 열립니다. 열리지 않으면 주소를 직접 입력합니다.

공부하는 동안 시작 창을 열어 두세요. 브라우저 탭만 닫아도 서버는 계속 실행됩니다.
종료하려면 시작 창에서 `Ctrl+C`를 누릅니다. 실행 중 다시 시작.cmd를 누르면 기존 서버를 재사용합니다.
같은 포트를 다른 프로그램이나 이전 버전이 쓰면 안내 후 종료합니다. 업데이트할 때는 기존 시작 창을 먼저 닫으세요.
압축 파일 안에서 실행하거나 `dist/app/index.html`을 직접 열면 안 됩니다.
배포 폴더를 옮겨도 기록은 사용자 폴더에 남습니다. 설치 후에는 학습·저장에 인터넷이 필요하지 않습니다.

다운로드한 `시작.cmd`도 Windows 정책에 따라 차단될 수 있습니다. 이 경우 압축 해제한
폴더에서 터미널을 열고 `node dist/server/index.js`로 실행합니다. 파일 차단 해제나
Smart App Control 비활성화는 필요하지 않습니다. 현재 PC에서는 시작.cmd 실행까지 확인했습니다.

## 학습과 기록

처음에는 진단 문제를 풀고 챕터별 시작점을 정합니다. **오늘의 학습**에서 복습과 새 문제를 추천받거나
**자유 연습**에서 문자·문법·단어·문장 범위를 직접 고릅니다. 문자표에는 기본 문자, 탁음·반탁음, 요음이 있습니다.
문제 답변은 자동 저장됩니다. 한 묶음의 **학습 마치기**까지 누르면 PC의 현지 날짜를 학습일로 기록합니다.
같은 날 여러 묶음을 끝내도 학습일은 한 번만 늘어납니다. 도중에 닫으면 저장된 다음 문항부터 이어 풀 수 있습니다.

여러 탭에서 동시에 학습하면 먼저 저장한 기록을 유지하고 오래된 탭의 저장은 거부합니다.
“다른 창에서 기록이 변경됐습니다” 안내가 나오면 페이지를 새로고침하세요.

전체 콘텐츠는 **2,001문항 · 189단원**입니다. N5/N4는 자체 분류이며 공식 시험 범위나 합격을 보장하지 않습니다.
[콘텐츠 범위와 검수 상태](docs/content-coverage.md)를 참고하세요.
일본어 음성이 브라우저에 제공될 때만 듣기를 사용할 수 있습니다. 음성이 없으면 텍스트로 공부합니다.
운영체제·브라우저의 음성 기능을 사용하며 별도 유료 음성 API는 호출하지 않습니다.

## 기존 Electron 기록 이어가기와 백업

Windows 사용자별 저장 위치는 이전 Electron 앱과 같습니다.

```text
%APPDATA%\일본어공부\study-data\progress.json
%APPDATA%\일본어공부\study-data\progress.json.bak
```

같은 Windows 계정에서 시작하면 기존 기록을 자동으로 읽습니다. 브라우저 쿠키나 사이트 데이터를 삭제해도
이 파일은 삭제되지 않습니다. 친구의 PC에는 친구의 기록이 따로 저장됩니다. 기록이 없을 때만 새 진단을 시작합니다.
백업·복원은 시작 창을 종료한 뒤 `study-data` 폴더 전체를 복사해서 진행합니다. 복원 전 현재 폴더도 별도로 보관하세요.
`.bak`는 직전 정상 저장본입니다. 손상된 파일은 백업으로 복구하고, 둘 다 손상됐을 때 임의로 초기화하지 않습니다.
**기존 Electron 앱과 웹앱을 동시에 실행하지 마세요.**

앱을 삭제하려면 시작 창을 닫고 배포 폴더를 삭제합니다. 학습 기록은 사용자 폴더에 남습니다.
기존 Electron 설치본은 Windows 설정 → 앱에서 별도로 제거할 수 있습니다.

## 개발

```powershell
npm ci
npm run make
npm start
```

`make`는 타입 검사 → 테스트 → 콘텐츠/ID 검사 → 화면·서버 빌드 → Windows ZIP 생성을 수행합니다.
개발 의존성은 제작할 때만 필요하며 배포 ZIP 사용자는 npm 설치가 필요 없습니다.
화면 수정 시 `npm run build`를 한 번 실행한 뒤 별도 터미널 두 개에서 실행합니다.

```powershell
# 터미널 1: 로컬 API (기존 진도 파일 사용)
npm run dev:server

# 터미널 2: 화면 변경 자동 반영
npm run dev
```

개발 화면은 http://127.0.0.1:5173 입니다. 실제 진도 대신 테스트 파일을 쓰려면 서버를 실행하는 터미널에서
`$env:JAPANESE_STUDY_DATA_PATH`에 별도 파일의 절대 경로를 지정합니다. 정상 실행에서 이 변수는 설정하지 않습니다.

## 프로젝트 구조

```text
src/app/       React 화면, 스타일, 브라우저 API·음성 연동
src/server/    루프백 HTTP 서버, 파일 저장·복구, 실행 진입점
src/learning/  진단, 추천, 복습, 콘텐츠 조합
src/content/   학습 자료와 문항 ID 기준표
src/shared/    화면·학습·서버가 공유하는 타입과 링크
public/        앱 아이콘
scripts/       콘텐츠 검사, ZIP 패키징
tests/         학습·UI·파일 저장·실제 HTTP 테스트
docs/          현재 구조·검증 기록, 과거 설계·검토 기록
licenses/      외부 콘텐츠와 폰트 라이선스
dist/          생성된 화면·서버·배포 ZIP (Git 제외)
```

현재 구조와 전환 검증은 [로컬 웹앱 문서](docs/local-web-app.md)를 참고하세요.
이전 Electron 서명 조사와 신청 초안은 [과거 기록](docs/archive/electron/README.md)으로 보관합니다.
SignPath 신청은 제출하지 않았으며 웹앱 전환으로 중단했습니다.
